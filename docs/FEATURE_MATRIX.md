# Feature matrix

| Area | Included |
|---|---|
| Window | Move, resize, viewport bounds, floating toggle, search, fullscreen |
| Navigation | Tabs, private tabs, subtabs, sections, groups, multi-sections |
| Input | Toggle, slider, dropdown, multi-dropdown, textbox, keybind, color picker, stepper, segmented |
| Composite | ToggleKeybind, ButtonKeybind, conditional enable/visible bindings |
| Display | Label, paragraph, divider, progress, stats, tags, cards, tables, grids |
| Media | Image, video, code, changelog, loadout and rating |
| Feedback | Notifications, dialogs, confirm, prompt, tooltip and popup |
| Appearance | Built-in themes, custom themes, accent, scale and transparency |
| State | Flags, callbacks, snapshots, restore and reset |
| Config | Profiles, import/export, autoload, migrations and injected storage adapter |
| Localization | Locale dictionaries, translation and locale bindings |
| Lifecycle | Janitor, Signal, instance pool and deterministic destroy methods |
| Runtime widgets | Keybind list, state list, watermark and floating bubble |

The table describes the current source tree. Refer to the module source and Studio tests for exact runtime support and limitations.
